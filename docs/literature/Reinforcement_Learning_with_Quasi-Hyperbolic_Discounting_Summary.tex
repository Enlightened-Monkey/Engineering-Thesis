\section*{Summary: Reinforcement Learning with Quasi-Hyperbolic Discounting}

\paragraph{Motivation}
Standard RL assumes exponential discounting. Quasi-hyperbolic (QH) $(\beta,\delta)$ preferences capture present-bias and align with behavioral evidence.

\paragraph{Values and Objectives}
For policy $\pi$ and state $s$:
\[
  W^\pi(s) = \mathbb{E}_\pi[ r(s,a) + \delta W^\pi(s')\mid s],\quad
  V^\pi(s) = \mathbb{E}_\pi[ r(s,a) + \beta\,\delta\, W^\pi(s')\mid s],
\]
with action-value counterparts $Q^C$ (continuation) and $Q^I$ (immediate-self):
\[
  Q^C(s,a) = \mathbb{E}[ r(s,a) + \delta \max_{a'} Q^C(s',a')],\quad
  Q^I(s,a) = r(s,a) + \beta\,\delta\, \mathbb{E}[ \max_{a'} Q^C(s',a')].
\]

\paragraph{Agent Types}
\emph{Naive}: acts as if future selves will not re-optimize. \emph{Sophisticated}: anticipates re-optimization; aims for a subgame-perfect equilibrium.

\paragraph{Algorithms}
\begin{itemize}
  \item Policy evaluation (QH-TD): learn $W$ via TD(0/\(\lambda\)) with discount $\delta$; compute $V$ by mixing with $\beta$.
  \item Off-policy control (QH-Q-learning): TD update for $Q^C$; act greedily w.r.t. $Q^I$; use double Q and target networks as needed.
  \item On-policy control (QH-SARSA): replace max with the next action in both $Q^C$ update and $Q^I$.
  \item Actor--critic (QH-AC): critic learns $W$; actor optimizes returns $G_t^{\beta,\delta}= r_t + \beta \sum_{k\ge1} \delta^k r_{t+k}$.
\end{itemize}

\paragraph{Theory}
The continuation operator $T_\delta$ is a contraction, ensuring tabular convergence for TD/Q-learning on $W/Q^C$ under standard conditions. Immediate-self values follow algebraically.

\paragraph{Practice}
Tune $\beta\in(0,1]$; share representation with two heads (continuation vs immediate-self); report both $W$ and $(\beta,\delta)$-returns. Use double/target networks for stability.

\paragraph{Key Phenomena}
Preference reversals, procrastination, and precommitment demand; differences between naive and sophisticated control.

\paragraph{Takeaways}
Separate learning of $\delta$-discounted continuation from action selection/evaluation under $(\beta,\delta)$. This bridges behavioral time preferences with practical RL.
