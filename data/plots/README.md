# Plots Directory

This directory contains generated figures and visualizations for the thesis.

## Structure

- `convergence/` - Convergence analysis plots
- `performance/` - Performance comparison charts
- `policies/` - Policy visualization plots
- `thesis_figures/` - High-quality figures for the thesis document
- `pole_balancing_100k.gif` - 10-second animation of the 100k-episode agent balancing the pole
- `pole_balancing_300k.gif` - 10-second animation rendered from the slower-learning 300k agent

## Figure Types

- **Learning curves**: Algorithm performance over time
- **Parameter studies**: Effects of σ and γ on performance
- **Policy comparisons**: Traditional vs QH optimal policies
- **Convergence analysis**: Value function and policy convergence
- **Statistical plots**: Box plots, error bars, significance tests

## File Formats

- `.png` - High-resolution plots for digital viewing
- `.pdf` - Vector graphics for LaTeX thesis document
- `.svg` - Scalable vector graphics for web presentation

## Usage

Plots are generated by the experiment runner:

```python
runner.generate_plots(results, 'performance_vs_sigma')
```

Pole-balancing GIFs can be reproduced with:

```bash
.venv/bin/python src/experiments/pole_balancing_simulation.py \
	--model data/models/pole_balancing_300k/<timestamp>.npz \
	--output data/plots/pole_balancing_300k.gif \
	--duration 10
```
