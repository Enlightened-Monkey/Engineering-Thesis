# Root Archived Plots

This directory contains plot files that were previously in the repository root and have been archived for better organization.

## Contents

These PNG files are outputs from various experiments and visualizations:

### Analysis Plots
- `Alpha_Analysis.png` - Analysis of alpha (present-bias) parameter effects
- `Sigmoid_alpha.png` - Sigmoid function visualization for alpha parameter

### Decision-Making Plots (Polish)
- `Decyzja_Emeryt_Drogi_Produkt_Pierwiastek.png` - Elderly/Expensive Product decisions
- `Decyzja_Młody_Bogacz_Tani_Produkt_Pierwiastek.png` - Young/Rich/Cheap Product decisions  
- `Decyzja_Student_Normalna_cena_Pierwiastek.png` - Student/Normal Price decisions
- `Decyzja_Student_Średni_Produkt_Pierwiastek.png` - Student/Medium Product decisions

### Experiment Results
- `Reward_Discount_combo.png` - Combined reward and discount analysis
- `choices_bar.png` - Bar chart of choices made
- `discount_curves.png` - Discount curves comparison
- `qh_discounting_apple.png` - QH discounting visualization (apple example)
- `reproduced_fig1.png` - Reproduction of Figure 1 from reference paper
- `inventory_convergence.png` - Convergence visualization for inventory MDP

## Usage

These plots may be referenced in documentation or used for comparison with new experimental results. They are preserved here rather than deleted to maintain a complete historical record of the project's development.

## Generation

Most of these plots were generated by scripts in `src/experiments/` and `scripts/`. New plots should be saved to `data/plots/` with appropriate subdirectories based on the experiment.
